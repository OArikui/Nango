# Python ランチャーとローカル保存

`run.py` は、Python の標準ライブラリだけで Nango-neo を起動し、辞書データをファイルへ自動保存するための小さなローカルサーバーです。追加パッケージのインストールは不要です。

## 起動方法

Windows:

1. ZIP を展開します。
2. `RUN_NANGO.bat` をダブルクリックします。
3. ブラウザーで Nango-neo が開きます。終了するときは、起動した黒いウィンドウで `Ctrl+C` を押します。

コマンドラインから起動する場合は、展開先フォルダーで `python run.py` を実行します（Python 3.9 以降）。

| オプション | 説明 |
| ---------- | ---- |
| `--port 9000` | ポート番号を指定します（既定: 8765）。使用中の場合は、続く 19 個のポートから空きを探します。 |
| `--no-browser` | ブラウザーを自動で開きません。 |

アプリは `127.0.0.1`（自分の PC）だけで待ち受け、外部ネットワークには公開しません。

## データの保存

- 登録・編集・削除・インポートなどの変更は、`user_data/nango_data.json` に自動保存されます。
- 次回起動時は、このファイルの内容を優先して読み込みます。
- ブラウザーの `localStorage` にも、予備として保存します。
- 保存できるデータは 1 回あたり 10 MB までです。
- `user_data` フォルダーをバックアップすれば、登録データを保管できます。このフォルダーは `.gitignore` で Git の管理対象外にしています。
- HTML を直接開いた場合は、ファイルへの自動保存は動作せず、`localStorage` だけに保存されます。大事なデータは定期的に JSON エクスポートしてください。

### 保存先の変更

設定の「ファイル保存先」で、辞書ファイルの保存先を絶対パスで指定できます。

- 指定先に既存のファイルがある場合は、既存データを上書きしないため、変更できません。別のファイル名を指定してください。
- 変更すると、現在の辞書データが新しい保存先へ書き出されます。
- 変更後の保存先は `user_data/settings.json` に記録され、次回起動時にも使われます。

## 画面の操作メモ

- 画面上部の「戻る」「進む」で、アプリ内の画面履歴を移動できます。
- 単語一覧は「単語」「読み」「分類」「タグ」などの見出しを押すと、その列を昇順・降順で切り替えます。
- タグ一覧は「タグ名」「該当単語数」の見出しを押すと、列ごとに昇順・降順を切り替えます。
