# PythonでNango-neoを起動する

## 起動方法（Windows）
1. ZIPを展開します。
2. `RUN_NANGO.bat` をダブルクリックします。
3. ブラウザーでNango-neoが開きます。
4. 終了時は起動した黒いウィンドウで `Ctrl+C` を押します。

Python 3.9以降を想定しています。追加パッケージのインストールは不要です。

コマンドラインから起動する場合は、展開先フォルダーで `python run.py` を実行します。
`python run.py --no-browser` でブラウザーを自動起動せず、`python run.py --port 9000` でポートを指定できます。

アプリはPC内の `127.0.0.1` のみで待ち受け、外部ネットワークには公開しません。データはブラウザーのローカルストレージに保存されます。大事なデータは定期的にJSONエクスポートしてください。

## 操作
- 画面上部の「戻る」「進む」でアプリ内の画面履歴を移動できます。
- 単語一覧は「単語」「読み」「分類」「タグ」の各見出しを押すと、その列を昇順・降順で切り替えます。
- タグ一覧は「タグ名」「該当単語数」の見出しを押すと列ごとに昇順・降順を切り替えます。


## ローカルファイルへの自動保存

Python ランチャーで起動すると、辞書データはブラウザー内だけでなく、
`user_data/nango_data.json` にも自動保存されます。次回起動時はこのファイルを優先して読み込みます。
`user_data` フォルダーもバックアップしてください。HTMLを直接開いた場合は、ファイルへの自動保存は動作しません。
