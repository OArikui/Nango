# DT-FMT（DTformats.neo.v5.16）仕様

Nango-neo の辞書データ形式です。アプリのインポート・エクスポート、`user_data/nango_data.json`、AI に単語を作らせるときの指示は、すべてこの形式に揃えています。

## 構成ファイル

`Nango-neo/DTformats.neo.v5.16/` に 3 つのファイルがあります。

| ファイル | 役割 |
| -------- | ---- |
| `DF-FMT_schema.v01.16.json` | JSON Schema（Draft 2020-12）。形式の正式な定義です。 |
| `DT-FMT_instruction_AI.v01.16.json` | AI に渡す指示つきのひな形。「AIに送るプロンプトをコピー」にも形式規則が含まれます。 |
| `DT-FMT_template.v02.16.json` | 記入例です。手書きで単語を作るときの雛形になります。 |

アプリの設定にある「DT-FMT定義を確認」でも、画面上で内容を確認できます。

## トップレベル

| キー | 型 | 必須 | 説明 |
| ---- | -- | ---- | ---- |
| `words` | object | 必須 | 単語名をキーとする辞書。キーが表示名です。 |
| `additional_data` | string の配列 | 任意 | 付加情報。既定は空配列です。 |
| `//comment_*` | string | 任意 | AI への指示コメント。AI 用ひな形・テンプレートに含まれます。 |

単語名は `words` のキーとしてだけ保持し、`word` や `word(any)` のような項目で重複して保存しません。

## 単語（`words` の値）

必須なのは `meanings` だけです。そのほかの項目は省略できます。項目は次の順に並べます（`pronunciation` が先頭です）。

| 項目 | 型 | 説明 |
| ---- | -- | ---- |
| `pronunciation` | string | 発音記号（IPA など）。単語名・`reading` とは別に保存します。 |
| `id` | integer（1 以上） | 管理用 ID。追加・インポート時にアプリが登録順で採番し直します。 |
| `datetime` | string | 登録日時。RFC 3339 形式（例: `2026-10-09T10:00:00+09:00`）。 |
| `category` | string | 旧版互換用の分類。`categoryTags` の先頭の値を保持します。 |
| `eraTag` | string | 時代区分のタグ。単語ごとに 1 つです。 |
| `reading` | string | 日本語の読み。単語名に括弧で付けず、ここに保存します。 |
| `kanji` | string | 漢字表記。ない場合は空文字にします。 |
| `english` | string | 英語・外国語表記、原語・正式名称。 |
| `column` | string | 言葉にまつわる豆知識や、深掘りしたエピソード。 |
| `memo` | string | 補足メモ。 |
| `gemini_note` | string | AI による一言コメント。 |
| `other_tags` | string の配列 | 単語に表示するハッシュタグ。分類・分野・時代の代用にはしません。 |
| `meanings` | 配列（1 件以上） | 意味の配列。下表を参照。 |
| `categoryTags` | string の配列 | 分類タグ。単語ごとに最大 3 個、重複不可、空文字不可。 |

## 意味（`meanings` の要素）

| 項目 | 型 | 必須 | 説明 |
| ---- | -- | ---- | ---- |
| `definition` | string（1 文字以上） | 必須 | 言葉の定義・意味。 |
| `background` | string | 任意 | 成り立ち、歴史、使われるようになった背景。 |
| `nuance` | string | 任意 | 与える印象、使い分けの傾向。 |
| `fieldTag` | string の配列 | 任意 | その意味が使われる分野・場面のタグ。意味ごとに最大 2 個。 |
| `examples` | string の配列 | 任意 | 例文。 |
| `synonyms` | string の配列 | 任意 | 類義語・言い換え。 |

## タグの使い分け

| タグ | 付ける単位 | 表すもの | 上限 |
| ---- | ---------- | -------- | ---- |
| `categoryTags`（と互換用の `category`） | 単語 | 言葉としての種類・形式・由来。例: 大和言葉、外来語、略語、専門用語、擬音語 | 3 個 |
| `fieldTag` | 意味 | その意味が使われる領域。例: IT、法律、医学 | 2 個 |
| `eraTag` | 単語 | 時代区分 | 1 個 |
| `other_tags` | 単語 | 表示用の補助ハッシュタグ | なし |

- タグは、配列の要素 1 つにつき 1 つずつ保存します。`IT・美容` のように、中点で複数のタグを連結しません。
- 中点が固有名詞の一部である場合（例: `チーム・バチスタ`）は、1 つのタグとして保持します。
- 専門用語だからといって、特定の分野タグを自動で付けません。定義・用例から意味ごとに判断します。
- 似たタグが増えないよう、登録済みのタグを優先して再利用します。

## 書き方のルール

- 単語名には見出し語だけを書きます。難読漢字も、単語名は漢字表記のままにして、読みは `reading` に書きます。
- 同じファイル内に、同一の単語名を重複させることはできません（インポート時にエラーになります）。

## 例

```json
{
  "words": {
    "カスケード": {
      "pronunciation": "",
      "id": 1,
      "datetime": "2026-10-09T10:00:00+09:00",
      "category": "外来語",
      "eraTag": "現代",
      "reading": "かすけーど",
      "kanji": "",
      "english": "cascade",
      "column": "",
      "memo": "",
      "gemini_note": "",
      "other_tags": [],
      "meanings": [
        {
          "definition": "連鎖的に物事が起きること。",
          "background": "",
          "nuance": "",
          "fieldTag": ["IT"],
          "examples": [],
          "synonyms": []
        }
      ],
      "categoryTags": ["外来語"]
    }
  },
  "additional_data": []
}
```

## 互換性

- アプリは、`words` がオブジェクトである v5.12 以降の形式を読み込めます。旧版アプリの単語配列 JSON は、移行用として取り込みます。
- エクスポートは常に v5.16 形式です。旧版アプリとデータを往復するときは、元データをバックアップしてください。
- 形式の変遷は [neo-versions.md](neo-versions.md) を参照してください。
