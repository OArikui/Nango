# Nango-NEO v2.7.3

## 修正内容

- サイドバーの階層・並び替えポップアップを通常フロー内に配置し、操作欄の重なりを解消。
- 表示モードをサイドバーの単語フィルタ設定より上に移動し、サイドバーの単語名へ適用。
- 単語詳細の操作ボタンを折り返し可能な通常レイアウトにして、単語名や分類バッジとの重なりを防止。
- DT-FMTの発音項目を単語オブジェクトの先頭に移動し、アプリのJSON出力・スキーマ・AI指示・テンプレートで順序を統一。
- 設定に「AIに送るプロンプトをコピー」を追加。DT-FMTの形式規則と登録済みタグ一覧を含めてコピー。
- 戻る／進むボタンを文字付きにし、履歴復元時に複数画面が同時表示されないよう修正。
- 単語一覧の単語名を枠なしの太字表示へ変更。
- 単語一覧で並び順を重複指定していたドロップダウンを削除し、カラム見出しのソートに一本化。
- ランチャー、GitHub Actions、スモークテストを v2.7.3 / DT-FMT v5.16 に更新。

## 検証

スモークテスト、Python構文チェック、DT-FMT JSON検証を GitHub Actions で実行する。
