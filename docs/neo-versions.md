## DT-FMT の変遷

現行の仕様は [DT-FMT.md](DT-FMT.md) を参照してください。

| バージョン | 変更内容 |
| ---------- | -------- |
| v5.16 | `pronunciation` を単語のプロパティの先頭へ移動。スキーマ・AI 指示・テンプレート・アプリの JSON 出力で順序を統一。 |
| v5.15 | 分類タグ `categoryTags`（単語ごとに最大 3 個）と発音 `pronunciation` を追加。`fieldTag` を意味ごとに最大 2 個に制限。`category` は旧版互換用（先頭の分類タグ）に。分類・分野・時代・その他タグの役割を、スキーマの説明と AI 指示で区別。 |
| v5.14 | 単語名へ読みを括弧で付ける形式を廃止。読みは `reading`、原語は `english` に分離。 |
| v5.13 | 表示名の読み表記を `見出し語（読み）` に統一（括弧は全角、括弧内は `reading` と一致）。 |
| v5.12 | `words` を、単語名をキーとするオブジェクトにした。複数の `meanings`、配列形式の `fieldTag`、`additional_data`、RFC 3339 の `datetime` に対応。 |

v5.15 を導入したアプリのバージョンは記録に残っていません（v2.6.0 の v5.14 と v2.7.3 の v5.16 の間です）。

##### **新規項目**

* *`"meaning"`* (list)

* *`"other_tags"`*（list）
    分野や時代だけでなく、「ステータス」「アクセシビリティ」などの細かい複数の関連タグ

* *`"memo"`* (str)  
    後述の特殊な符号,また、userのメモ、自由記述欄`言葉を知ったきっかけなど`

* *`"gemini_note"`* (str)  
    Geminiの一言。Frashmodeだとmemoに自分の一言を書き始めるので追加したが、存外悪くないので維持
