# Nango-neo v3.1.0

リリース日: 2026-10-16

## 追加

- 登録済みの単語と意味を使ったクイズ機能を追加。
- クイズ専用 HTML へ移動して出題する方式に変更。アプリ本体のヘッダー、ツールバー、サイドバー、単語詳細をクイズ画面に表示しません。
- 「単語から意味を選ぶ」「意味から単語を選ぶ」「2形式を組み合わせる」の3形式、問題数指定、回答後の採点、辞書に登録された補足説明に対応。
- 起動時に現在の辞書データをセッション内でクイズページへ渡すため、Supabase ログイン中の辞書も利用できます。クイズ結果はその場で表示し、辞書データは変更しません。

## バージョン

- HTML: `Nango-neo.v03.1.0.html`
- JavaScript: `Nango_main.v02.0.2.js`
- CSS: `style.v02.8.1.css`（変更なし）
- クイズ画面: `Nango-quiz.v01.0.0.html` / `Nango-quiz.v01.0.0.js` / `Nango-quiz.v01.0.0.css`
- DT-FMT: v5.17（変更なし）
