# Nango-neo v3.0.0

日付: 2026-10-16

## 変更内容

- Supabase 設定を JSON ファイルで読み込む構成を継続。
- 新規登録時にプライバシーポリシーの確認と同意を必須化。未チェックの場合、登録処理を行わない。
- アプリを v3.0.0、JavaScript を v02.0.0 に更新。

## 公開前の確認事項

- `Nango-neo/supabase-config.json` の `url` と `publicKey` は公開用の値を設定する。秘密鍵や service_role キーは絶対に使用しない。
- Supabase の RLS が有効であることを確認する。
- プライバシーポリシーの運営者情報と問い合わせ窓口を実際の運用に合わせて確定する。
- 実際の Supabase プロジェクトを使った認証・クラウド保存試験は、接続情報が空欄の間は実施できない。
