# Nango-neo v3.0.1

リリース日: 2026-10-16

## 改善

- アプリ内で別画面へ移動する前のスクロール位置を履歴へ保存し、「戻る」「進む」で復元するように変更。
- 単語詳細を新しく開いた際はページ上端から表示。詳細表示中にサイドバーや本文中の単語リンクから別の単語を開く場合は、スクロール位置を維持して表示のがたつきを抑制。
- 一定量スクロールすると右下に小型の「ページ上部へ戻る」ボタンを表示。
- 詳細画面の見出し語と「この単語を編集」「削除」ボタンを同じ行に配置し、縦方向の余白を削減。

## バージョン

- JavaScript: `Nango_main.v02.0.1.js`
- CSS: `style.v02.8.1.css`
