# Nango-neo v3.4.0

## 単語登録数・閲覧数の推移グラフ

- 既存の単語データに記録された RFC 3339 の `datetime` から登録数を再集計。日別・週別（月曜始まり）・月別の登録件数と累計を表示。
- 単語詳細を表示したときに閲覧イベントを新規記録し、日別・週別・月別に集計。
- 登録数・登録累計・詳細閲覧数を、外部グラフライブラリを使わずSVGで描画。
- 統計ビューは既存の「ツール」画面に追加。集計単位を切り替えて表示可能。

## 保存先とプライバシー

- 未ログイン時の閲覧統計は localStorage に保存。
- ログイン時の閲覧イベントは `public.nango_user_view_events` にユーザーIDと紐付けて保存。RLSで本人のイベントのみ読み書き可能。
- オフライン時の閲覧イベントはユーザーID別に送信保留し、オンライン復帰後に再送。イベントIDで重複登録を防止。
- 閲覧イベントは辞書データ、DT-FMT、JSONエクスポートに含めない。
- 閲覧記録は本機能の導入後に開始するため、過去の閲覧数は復元できないことを画面とドキュメントに明記。

## 互換性・バージョン

- 登録数集計には既存の `datetime` を利用し、新しい辞書項目やDT-FMT更新は不要（v5.17のまま）。
- HTML: `Nango-neo.v03.4.0.html`
- JavaScript: `Nango_main.v02.0.8.js`
- CSS: `style.v02.10.0.css`
- Supabase利用者は更新した `docs/supabase-setup.sql` をSQL Editorで実行してください。
