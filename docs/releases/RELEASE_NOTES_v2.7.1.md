# Nango-NEO v2.7.1 — UI regression fixes

## 修正内容

- サイドバー、ツリー、メインコンテンツの HTML 構造を修正し、サイドバーを左側に正しく配置。
- 分類フィルターをボタンから開くポップオーバーに変更。ポップアップを通常フローから外して高さの変化を防止。
- 上部ツールバーをスクロール追従に変更。ブランドヘッダーは固定せず、ツールバー上下の半透明ラインで区切りを追加。
- 詳細の項目見出しを太字にし、解説本文にインデントを適用。
- 単語一覧のグループを現在の並び替えカラム（単語・読み・分類・タグ・登録日）に連動。
- グループ区切りをクリックすると、ほかのグループへジャンプするメニューを表示。
- 階層基準を変更した際、グループ表示を自動的に有効化。
- HTML/CSS/JavaScript のファイル名と内部バージョンを v2.7.1 に更新。

## 検証

GitHub Actions で Node.js の Phase 1 smoke test、Python ランチャーの構文チェック、DT-FMT JSON の妥当性を確認します。
