# Nango-neo v3.1.2

リリース日: 2026-11-02

## UI 改善

- アカウント画面のメール認証状態を、メールアドレスの右側に小さく表示するバッジへ変更。
- メール認証済み・未認証を色と記号で区別し、未ログイン時は認証バッジを表示しない。
- ページヘッダー右上にアカウントステータスを追加。
- ログイン中は現在のメールアドレスを表示し、未ログイン時はアカウント画面（ログイン画面）へ移動するボタンを表示。
- ログイン・ログアウト・起動時のセッション復元に合わせて、ヘッダーの表示を更新。

## バージョン

- HTML: `Nango-neo.v03.1.2.html`
- JavaScript: `Nango_main.v02.0.5.js`
- CSS: `style.v02.8.3.css`
- DT-FMT: v5.17（変更なし）

## 確認

スモークテストでヘッダーのメールアドレス欄、ログインボタン、認証バッジの HTML/CSS/JavaScript を確認します。認証状態の実際の切り替えは Supabase のセッションを使ってブラウザー上で確認してください。
