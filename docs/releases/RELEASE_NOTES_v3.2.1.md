# Nango-neo v3.2.1

## リリース・ドキュメントページ

- アプリのメニューに「リリース・ドキュメント」を追加し、アプリ内から更新履歴・仕様書・開発資料へ移動できるようにしました。
- リリースノートをバージョン順に一覧表示し、選択した本文をページ内で閲覧できる専用ページを追加しました。
- README、docs 配下の仕様・運用・開発資料、SQL セットアップスクリプト、アーカイブ資料を一覧化し、タイトル・ファイル名で検索できるようにしました。
- GitHub API から一覧と本文を取得するため、docs の追加・更新がページ側の固定リスト変更なしで反映されます。
- GitHub Releases が未登録の場合も、リポジトリ内の docs/releases に保存したリリースノートを表示します。

## 互換性・制限

- アプリ本体、JavaScript、CSS、DT-FMT v5.17 のデータ形式は変更しません。
- ドキュメントページの一覧と本文の読み込みにはインターネット接続が必要です。ページ本体は Service Worker のキャッシュ対象に含めます。
- GitHub API の利用上限やネットワーク障害が発生した場合は、GitHub 上の対象ファイルを直接開けるリンクを利用できます。
