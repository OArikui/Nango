# Nango-neo v3.1.1

リリース日: 2026-11-02

## 追加

- アカウント画面から遷移する独立した新規登録ページを追加。
- メールアドレス、パスワード、確認用パスワードを入力し、プライバシーポリシーへの同意を確認してから登録するように変更。
- アカウント画面にメール認証状態を表示。
- 登録後は「メール認証結果」ページで確認待ち・認証済みを表示し、確認メールの再送にも対応。
- 確認リンクから Nango に戻った際、Supabase Auth の `email_confirmed_at` を再取得して認証結果を表示。

## バージョン

- HTML: `Nango-neo.v03.1.1.html`
- JavaScript: `Nango_main.v02.0.4.js`
- CSS: `style.v02.8.2.css`
- DT-FMT: v5.17（変更なし）

## 確認

GitHub Actions のスモークテスト、登録ページ・認証結果ページの構造確認、メール認証処理の静的チェック、ドキュメント整合性テスト、DT-FMT スキーマ検証で確認します。実際のメール配送とリンク認証は Supabase プロジェクトの設定を必要とします。
