# Nango-neo v2.8.2

日付: 2026-10-13

## 修正内容

- JSONファイルのインポート、JSON貼り付け後に、取り込んだ単語（新規追加・既存単語へのマージ対象）のみに絞り込んだ単語一覧を表示するよう修正。
- 置き換えインポートでは、重複統合後の単語一覧を表示するよう修正。
- 「クリップボードから貼り付け」ボタンを、クリップボード内容の取得だけで終わらせず、取得したJSONの取り込みまで続けて実行するよう変更。
- インポート対象IDを保持し、複数単語も一覧で正しく絞り込めるよう修正。
- アプリを v2.8.2、JavaScript を v01.7.5 に更新。DT-FMT v5.17 は変更なし。

## 検証

- Node.js スモークテストで、複数単語の絞り込みとクリップボード取得後の自動取り込みを確認。
- GitHub Actions で、スモークテスト、ドキュメント整合性、DT-FMT スキーマ検証、Python 構文、JSON 検証を実行。
