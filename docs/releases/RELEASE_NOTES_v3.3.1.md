# Nango-neo v3.3.1

## リリース・ドキュメントポータル

- アプリのメニューに「リリース・ドキュメント」を追加し、アプリを離れずに更新履歴・仕様・開発ガイドへ移動できるようにしました。
- リリースノートをバージョン順に一覧表示し、選択した本文をページ内で閲覧できるポータルページを追加しました。
- README、docs 配下の仕様・運用・開発ガイド、SQL セットアップスクリプト、アーカイブ済み資料を一覧化し、タイトルとファイル名で検索できるようにしました。
- GitHub API から一覧と本文を取得するため、docs の追加・更新がページ側の固定リスト変更なしで反映されます。
- GitHub Releases に未登録の場合も、リポジトリ内の docs/releases に保存されたリリースノートを表示します。

## 修正

- マージ時に残っていたバージョン表記の競合マーカーを解消し、HTML・README・ランチャー・Service Worker のバージョンを v3.3.1 に統一しました。

## 互換性・注意

- アプリ本体の機能、JavaScript、CSS、DT-FMT v5.17 のデータ形式は変更しません。
- ドキュメントページの一覧と本文の読み込みにはインターネット接続が必要です。ページ本体は Service Worker のキャッシュ対象に含めます。
- GitHub API の利用がネットワーク障害などで失敗した場合は、GitHub 上の対象ファイルを直接開くリンクを利用できます。
- HTML: `Nango-neo.v03.3.1.html`
- JavaScript: `Nango_main.v02.0.7.js`
- CSS: `style.v02.9.1.css`
