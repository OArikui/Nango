# Nango-NEO v2.7.2 — PR #5 review follow-up

## 変更内容

- フィルターポップアップのレイヤーと幅を調整し、サイドバー内の操作要素と重なりにくくする。
- 上部ツールバーの区切り線を上側のみへ変更。ボックスより少し上に、左右に余白を取って表示。
- 頭文字グループを単語表記ベースに変更。アルファベット・数字・ひらがな・カタカナは先頭文字ごと、漢字は「漢字」、記号などは「記号・その他」にまとめる。
- 単語一覧の列見出しを固定し、スクロール中は現在のグループも固定表示。
- 分野タグ、時代タグ、その他タグを別々のカラムへ分離し、カラム別ソートを追加。
- 検索欄の文言を「検索」に統一し、分類タグの指定欄を検索欄の直下で見つけやすくする。
- ヘッダーの主メニューを「今日の単語・単語一覧・タグ一覧・ツール・設定」の順に整理。
- JSONインポート・エクスポート・リセットをツールへ移動。エクスポートは標準色にし、JSON貼り付けと新規単語追加をヘッダー右側に配置。
- DT-FMTの確認とAI指示用タグ一覧を設定へ移動。
- HTML/CSS/JavaScript/ランチャーを v2.7.2 に更新し、回帰テストを追加。

## 検証

GitHub Actions で Node.js smoke test、Pythonランチャーの構文チェック、DT-FMT JSON の妥当性を確認。
