# Nango-NEO v2.6.0

## UI刷新
- 配色、余白、角丸、境界線、影を統一し、落ち着いたモダンな知識管理UIへ刷新。
- ヘッダーにブランド表示とアプリバージョンを追加。
- ツールバー、検索欄、階層ツリー、フォーム、テーブル、ボタンの視認性と操作フィードバックを改善。
- 画面幅に応じてサイドバーとツールバーが再配置されるレスポンシブ表示を追加。
- キーボードフォーカス表示と動きを抑えるOS設定への配慮を追加。

## バージョン
- アプリ: v2.6.0
- HTML: `Nango-neo.v02.6.0.html`
- JavaScript: `Nango_main.v01.6.0.js`
- CSS: `style.v02.6.0.css`
- データ形式: DTformats.neo.v5.14（変更なし）

## 互換性
- 既存のJavaScript関数・DOM ID・データ形式は維持し、スタイルとリリース名を中心に更新。
- ローカル保存データ `user_data/nango_data.json` はそのまま引き継ぎ可能。
