# Nango-neo v3.0.2

リリース日: 2026-11-01

不具合の修正と、コード・ドキュメント・テストの整合性の改善です。データ形式（DT-FMT v5.17）と保存データに変更はありません。

## 修正

### セキュリティ

- Python ランチャー（`run.py`）の `/api/*` が、Host・Origin・Content-Type を検証していませんでした。閲覧中の外部サイトから `text/plain` の POST を送るだけで、`user_data/nango_data.json` の上書きや、任意の絶対パスへのファイル作成と `settings.json` の書き換えができる状態でした。次の要求だけを受け付けるように変更しました。
  - `Host` が `127.0.0.1:<port>` または `localhost:<port>`（DNS リバインディング対策）
  - `Origin` がない、またはランチャー自身（クロスサイト要求の遮断）
  - `Content-Type: application/json`（ブラウザーにプリフライトを強制し、単純リクエストでの書き込みを遮断）
- Supabase JavaScript ライブラリの読み込みを `@2`（常に最新の 2.x）から `@2.117.3` に固定し、SRI（`integrity`）で検証するように変更しました。CDN 側の更新や改ざんで、ログイン周りの挙動が予告なく変わることを防ぎます。

### 画面・操作

- 「アカウント」画面を開いたまま「＋ 新規単語追加」「この単語を編集」を押すと、アカウント画面と編集フォームが同時に表示される不具合を修正。画面の切り替えを `hideAllPanels()` に一本化し、HTML のパネルと一覧がずれないようテストで検査します。
- 「アカウント」画面が「戻る」「進む」の履歴に記録されず、履歴で戻ると詳細画面に飛ぶ問題を修正。
- タグのマージ確認ダイアログに `\n` が文字のまま表示される問題を修正。
- インポート方法の選択で「キャンセル」を押すと確認なしに辞書全体が置き換わる問題を修正。置き換える前に件数を示して再確認し、中止するとデータを変更しません。
- 「ローカル辞書でクラウドを置き換える」が失敗したとき、クラウド同期が黙って停止していた問題を修正。失敗時は元の同期状態を維持します。
- 容量不足などで `localStorage` に書き込めないとき、削除・タグ改名などの操作が途中で例外になる問題を修正。画面に保存失敗を表示し、操作は続行します（エクスポートでのバックアップを促します）。
- JSON エクスポートで、ダウンロード開始前に URL を破棄してしまう可能性があった処理を修正（Safari など）。
- 登録済みの単語が `amp` や `lt` のとき、文章中の `&amp;` などの文字参照を壊してリンク化する問題を修正。
- DT-FMT 確認画面が、GitHub Pages や HTML 直接起動では読み込めなかった問題を修正。ランチャーの API が使えない場合は、同梱の DT-FMT ファイルを直接読み込みます。
- ランチャーがない環境で、存在しない `/api/data` / `/api/data-path` に毎回リクエストしていた処理を削減。

### データ形式との整合

- 分野タグが 2 個を超える意味（最大 2 個）や、分類タグが 3 個を超える単語（最大 3 個）を含むデータは、インポートできてもエクスポートがスキーマ検証に失敗していました（同梱の `data/` のデータでは 121 件の意味が該当）。取り込み時の結果ダイアログとツール画面の統計に、該当件数を表示するようにしました。データ自体は自動で書き換えません。
- マージ時の競合反映が、メッセージ文字列の `の` での分割に依存していた処理を、明示的なキーに変更。

### 整理

- 存在しない `wordListSort` / `wordListDirection` を参照していた単語一覧の並び替えコードと、未使用の `setWordListSort()` を削除。
- `writeCloudDocument()` の引数が、グローバルの `document` を隠していたため改名。

- `CONTRIBUTING.md` の例 `v03.00.0` を `v03.0.0` に、進捗欄の「現行は v5.16」を現行形式への案内に修正。`PHASE1_IMPLEMENTATION.md` の、存在しない `DTformats.neo.v5.16/` への参照を修正。`ROADMAP.md` の実装状況を更新。

## 互換性

- 保存データ（`user_data/nango_data.json`、`localStorage`、Supabase）に変更はありません。
- HTML のファイル名が変わります。旧ファイル名をブックマークしている場合は、開き直してください。
- ランチャーの API は、ランチャーが開く画面以外からは使えなくなります。別ツールから `/api/*` を直接呼んでいる場合は、`Content-Type: application/json` と `Host: 127.0.0.1:<port>` を付けてください。
