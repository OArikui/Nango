# Nango-neo v2.8.1

日付: 2026-10-13

## 変更内容

- DT-FMT を v5.17 に更新し、意味ごとに antonyms（対義語）と similarWordsDifference（似た言葉との違い）を追加。
- 単語追加・編集フォームと詳細画面に新しい2項目を追加し、旧版データでは未登録値を空欄として補完。
- 設定からコピーする AI プロンプトを拡張。全項目を省略せず出力すること、不明値は空文字／空配列とすること、複数の意味・十分な説明・語源や文化的な補足を促すことを明記。
- 新規単語の保存後に加え、JSONファイル・貼り付けの取り込み後も、取り込んだ（追加・マージされた）単語だけに絞った単語一覧を表示。
- クリップボードボタンは内容取得後、そのままJSON取り込みまで実行。
- JSON 貼り付け画面にクリップボード読み取りボタンを追加。ブラウザー権限や API が利用できない場合は通常の Ctrl+V を案内。
- 編集可能な入力欄では通常のカーソル操作を維持しながら、左右矢印キーでアプリ内の戻る／進む履歴を操作可能に。
- HTML を v02.8.1、JavaScript を v01.7.4 に更新。CSS は変更なしのため v02.7.3 を維持。

## 検証

- DT-FMT の JSON Schema・AI 指示・テンプレート・サンプルを v5.17 に整合。
- Node.js スモークテスト、Python の JSON Schema テスト、ドキュメント整合性テスト、Python 構文チェックを更新対象に含めた。
