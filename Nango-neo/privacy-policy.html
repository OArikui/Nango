プライバシーポリシー

最終更新日：2026年10月16日

本ポリシーは、Nango-neo（以下「本アプリ」）における情報の保存、利用、外部サービスとの通信について説明します。本アプリは、利用者が単語・意味・タグなどを管理するための辞書アプリです。

1. 取り扱う情報

  • ローカル利用時の辞書データ：単語、読み、定義、例文、タグ、メモなど、本アプリに入力した内容。未ログイン時は原則として利用中のブラウザーの localStorage に保存されます。
  • アカウント情報：クラウド同期を利用する場合のメールアドレス、認証ユーザー ID、認証セッションなど。パスワード認証は Supabase Auth に送信され、本アプリのコードがパスワードを独自のデータベースへ保存することはありません。
  • クラウド辞書データ：ログイン中に同期する辞書データ。Supabase のデータベースにユーザー ID と関連付けて保存されます。
  • サービス運用情報：ホスティング、認証、CDN などの事業者が、サービス提供・セキュリティのために処理する IP アドレス、アクセス日時、リクエスト情報等。取得・保存の範囲は各事業者の運用とポリシーによります。

2. 情報の利用目的

本アプリは、辞書データの保存・表示・検索、アカウント認証、利用者ごとのクラウド同期、障害対応、安全性の確保、問い合わせへの対応のために情報を利用します。

3. 保存先と外部サービス

  • 未ログイン時：辞書はブラウザーの localStorage に保存されます。ブラウザーのデータ削除、プロファイル変更、端末の故障などで失われる可能性があるため、必要に応じて JSON エクスポートでバックアップしてください。
  • ログイン時：辞書データは Supabase のクラウドデータベースへ同期されます。Supabase の認証・データ提供サービスが、アカウントとクラウド保存の処理を行います。
  • 配信・ホスティング：本アプリは GitHub Pages で配信される場合があり、Supabase JavaScript ライブラリを jsDelivr CDN から読み込みます。これらのサービスへの通信には各事業者の規約・プライバシー方針が適用されます。

未ログインで利用している辞書データは、利用者がログインやクラウドへのコピーなどの同期操作をしない限り、クラウド辞書として保存されません。ログアウトしても Supabase に保存された辞書は削除されません。

4. 第三者提供

本アプリの管理者は、利用者の個人情報を販売しません。サービスの稼働に必要な範囲で、前項に記載したホスティング、認証、データ保存、CDN 等のサービス事業者が情報を処理することがあります。法令に基づく場合を除き、管理者が独自に個人情報を第三者へ提供することを意図していません。

5. Cookie・解析ツール

本アプリは、独自の広告配信やアクセス解析ツールを組み込んでいません。ログイン状態を維持するため、Supabase のクライアントライブラリがブラウザー内に認証セッションを保存します。外部サービスが利用する技術や運用ログについては、それぞれの事業者の説明を参照してください。

6. 安全管理

クラウド辞書はユーザー ID に基づく Row Level Security（RLS）でアクセスを制限する構成です。ただし、インターネット通信や端末上の情報について、あらゆる危険を完全に排除できることを保証するものではありません。公開設定では Supabase の秘密鍵を使用せず、RLS を有効にして運用する必要があります。

7. 保存期間・削除

ローカル辞書は、利用者がブラウザー内データを消去するまで保存されます。クラウド辞書は、利用者が削除するか、アカウント・データの削除対応が行われるまで Supabase に保存されます。ログアウトやブラウザー側のデータ消去だけではクラウド辞書は削除されません。本アプリにアカウント全体を削除する専用ボタンはありません。

8. 利用者自身による管理

利用者は、本アプリの JSON エクスポートを利用して辞書をバックアップできます。共有端末ではログアウトし、必要に応じてブラウザー内データを削除してください。クラウド同期を利用する前に、保存内容と共有端末の状況をご確認ください。

9. ポリシーの変更

機能や外部サービスの変更に応じて、本ポリシーを更新する場合があります。重要な変更は、本ページの更新日を変更して掲載します。

10. 運営者・お問い合わせ

運営者：Nango-neo プロジェクト管理者

一般的な仕様に関する連絡は、GitHub リポジトリの Issue を利用できます。Issue は公開されるため、メールアドレス、アカウント情報、辞書データなどの個人情報を投稿しないでください。個人情報の開示・削除などの相談を扱う場合、運営者は公開運用前に非公開の問い合わせ窓口を別途用意し、この項目を更新する必要があります。
